# Deprecated

Everything under `auto/` belongs to the legacy automated mode. It is kept only while the scheduled `apps.yml` workflow still runs `auto/scripts`, and it will be removed once that workflow is migrated to the current patch selection settings.

The Tasker project automation is broken and is no longer maintained. Manually triggered builds, scheduled auto updates and Obtainium support are unaffected.

Documentation now lives in [`/docs`](../docs). Files here are excluded from pre-commit and receive no further changes.
